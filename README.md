# Customer-Churn-Analysis

## 📌 Overview

Customer churn is an important business challenge that can affect customer retention and revenue.

This project analyzes customer churn data to understand customer behavior, identify churn patterns, and generate meaningful business insights.

The project covers data analysis using Python and Pandas, numerical analysis with NumPy, SQL-based business analysis, and interactive visualization using Power BI.

---

## 🎯 Objectives

The main objectives of this project are to:

* Analyze customer churn patterns
* Understand customer behavior
* Compare churned and retained customers
* Identify important trends and patterns in the data
* Perform business analysis using SQL
* Create an interactive Power BI dashboard
* Generate meaningful insights from the analysis


## 🗂️ Dataset

The dataset contains customer-related information used to analyze customer behavior and churn.

The analysis includes customer attributes, service-related information, churn status, and other relevant business metrics.


## 🛠️ Tools & Technologies

* **Python** – Data analysis and processing
* **Pandas** – Data cleaning, manipulation, and analysis
* **NumPy** – Numerical operations and data analysis
* **SQL** – Data querying and business analysis
* **Power BI** – Interactive data visualization and dashboard creation
* **Jupyter Notebook** – Python-based data analysis


## 🔄 Project Workflow

### 1. Data Loading

* Loaded the dataset into Python using Pandas
* Inspected the dataset structure and dimensions
* Reviewed column names and data types
* Performed an initial data inspection

### 2. Data Cleaning

* Checked for missing values
* Identified duplicate records
* Checked data types
* Reviewed inconsistent values
* Prepared the dataset for analysis

### 3. Exploratory Data Analysis (EDA)

Performed exploratory analysis to understand:

* Customer distribution
* Churn distribution
* Churn rate
* Customer segments
* Revenue-related patterns
* Differences between churned and retained customers
* Relationships between customer attributes and churn

### 4. SQL Analysis

Used SQL to perform business-focused analysis, including:

* Total customers
* Total churned customers
* Churn rate
* Average revenue
* Customer segmentation
* Churn across different categories
* Comparison of customer groups
* Other key business metrics

### 5. Power BI Dashboard

Created an interactive Power BI dashboard to present the analysis visually.

The dashboard includes:

* Total Customers
* Churned Customers
* Churn Rate
* Revenue-related metrics
* Churn analysis by different categories
* Interactive filters
* Charts and visualizations


## 📊 Dashboard

The Power BI dashboard provides an interactive view of customer churn patterns and helps identify important trends across different customer segments.


## 💡 Key Insights

The analysis helps identify:

* Overall customer churn patterns
* Differences between churned and retained customers
* Customer groups with different churn behavior
* Revenue patterns across customer segments
* Important factors associated with customer churn
* Areas that may require further customer retention analysis


## 📌 Conclusion

This project demonstrates an end-to-end data analytics workflow using **Python, Pandas, NumPy, SQL, and Power BI**.

The analysis transforms customer data into meaningful insights by combining data cleaning, exploratory analysis, SQL queries, and interactive visualization.
